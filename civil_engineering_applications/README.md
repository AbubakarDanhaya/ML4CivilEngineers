# Civil Engineering Applications

This folder contains practical applications of **Python, data-driven techniques, and machine learning** to solve real-world **civil engineering problems**.

The goal is to demonstrate how classical civil engineering theories can be **automated, simulated, and visualized** using modern computational tools, while laying the foundation for future machine learning integration.

These mini projects are designed to be:
- Easy to understand
- Engineering-focused
- Suitable for teaching, learning, and experimentation

---

## 📂 Available Applications

### 1️⃣ Settlement Analysis
**Folder:** `settlement_analysis/`

A mini project demonstrating how geotechnical settlement analysis can be performed using Python.

**Topics covered:**
- Primary consolidation settlement (Terzaghi theory)
- Time–settlement analysis
- Numerical simulation using Python
- Visualization of settlement behavior

This project shows how traditional geotechnical calculations can be translated into reusable and scalable Python code.
